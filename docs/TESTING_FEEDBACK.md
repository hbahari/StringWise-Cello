# StringWise Cello: testing feedback and what changed

A running log of feedback on StringWise Cello, in plain language, with the change made in
response. Newest entries are at the bottom of each section, and new sections are added as
testing continues.

**Where the feedback came from**

- **Closed test**: reported by testers during the Google Play closed test.
- **Device testing**: found by the developer while testing builds on a phone and a computer.
- **Play Console**: raised by Google Play's own checks on an uploaded build.

Keeping the two apart matters when answering Google's questions about tester feedback.

---

## 21 November 2026 (version 1.0.0)

StringWise Cello starts from StringWise (violin) 2.4.0, with the same screens, timing
features, Record and Check and settings. What is different:

| Area | Change for the cello |
| --- | --- |
| Strings and tuner | C, G, D, A (65.4, 98, 146.8 and 220 Hz). Pitch detection now reaches down to 56 Hz and reads the C string correctly even when a phone microphone barely hears its fundamental. |
| Finger pattern | Cello first position: a whole step to finger 1, then a half step per finger. Major keys use fingers 1, 3 and 4. Finger 2 on the C and G strings is shown as E♭ and B♭. |
| Sheet music | Bass clef. Every piece is the violin piece moved down an octave and a fifth, so each violin string maps onto the matching cello string (violin A string to cello D string) and every note stays in first position. Keys are G and C major instead of D and G major. |
| Lessons | Rewritten for sitting posture, endpin, cello bow hold, the cello left-hand frame and cello bow-arm levels. The fourth-finger check is now the octave ring with the open string below. Weeks 3 and 4 swapped a piece each, so finger 4 arrives in week 4 as before. |
| Theory, Fingers, Tuner, Practice | All text rewritten for the cello. |

## 23 November 2026 (version 1.1.0)

Brought over from StringWise (violin) 2.5.0, which added these after the Testers Community report.

| Feedback | Source | What changed |
| --- | --- | --- |
| New users did not know where things were. | Closed test (violin) | A short tour runs the first time the app opens. It spotlights one thing on each tab, with Skip and Next, and ends on week 1. It can be shown again from Settings. |
| There was no easy way to tell a friend about the app. | Closed test (violin) | Settings has a Share button that opens the phone's share sheet with a link to the app. |
